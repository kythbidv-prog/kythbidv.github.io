Privacy Policy – HealthExport

HealthExport is a personal tool used only by its owner.

Data accessed

With the owner's consent, HealthExport reads the owner's Google Health data: activity (steps, distance, floors, calories, exercise), sleep, heart rate, weight, and basic profile settings.

How data is used

The data is used only to create a personal health summary that is sent to the owner's own Telegram account. It is not sold, shared with third parties, or used for advertising. Data is processed temporarily and is not stored on any server.

Limited Use

HealthExport's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
